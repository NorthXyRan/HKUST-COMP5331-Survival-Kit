# Past exams

No complete past-exam PDFs are currently stored in this repository. These external pages identify COMP5331 final-exam papers:

| Semester | Resource | Access checked on October 9, 2026 |
| --- | --- | --- |
| Fall 2019 | [Course Sidekick: online final examination](https://www.coursesidekick.com/computer-science/2727787) | 12-page document; preview available, full access requires unlocking |
| Fall 2020 | [Course Hero: 2020exam.pdf](https://www.coursehero.com/file/194949270/2020exampdf/) | 10-page document; preview available, full access requires unlocking |

The semester is taken from the paper's heading, rather than the website's upload date. External availability can change.

When adding a paper, place it under its semester, for example `Exams/2020Fall/final.pdf`, and record the source in [SOURCES.md](../SOURCES.md). Label question papers and solutions separately.
